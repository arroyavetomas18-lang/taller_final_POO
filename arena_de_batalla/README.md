# Descripcion
Arena de batalla es un juego de turnos el cual funciona como una torre de enemigos (parecida a el modo de juego de Mortal Kombat), el jugador tiene q ir matando todos los enemigos que se vaya enfrentando, estos salen aleatoriamente y por cada enemigo derrotado aumenta sus estadisticas un 3% haciendo que sea un poco mas complicado ganar y pasar la torre, para que no sea imposible el jugador tiene una pocion q cura 70 puntos de vida, esta se da por defecto cada vez que se incia y cada vze que mata 2 enemigos

# Tecnologias
- Python para hacer el codigo
- Visual studio para ir haciendo pruebas
- Tkinter, la libreria que se uso para hacer todo lo de la intefaz
- Meta AI para crear la imagen de fondo

# Instalacion y ejecucion
Primero se instala el .zip donde tiene todos los archivos, el main, el readme, requeriments y una carpeta que se llama Src que contiene la interfaz, el juego, la foto del fondo y el __init__ que es el archivo que le dice a Python que src es un paquete que no se puede borrar
